# 全城破坏 v0.8

外围 78 栋楼体、14 位路人、8 辆交通车、两辆警车和警员、车库六个结构部件都加入受损与破坏。原有主楼、便利店、双层住宅、仓库和街区道具继续使用既有体素破坏系统。暖色立面、门窗和街区布局保留。

AK 和激光会击中当前可见的最近实体。楼块被打掉后，射线、步行与车辆碰撞使用同一份占用数据，缺口可以通行。拆掉任一层 65% 的支撑会触发整栋坍塌；坍塌时有下落楼板和碎片，最多 96 片视觉碎屑。坍塌碎屑会消退，不形成持久的实体废墟。外围楼体是可破坏体块，没有新增家具与完整室内装修；原有三栋室内建筑可以进入与上下楼。

人物受击会闪烁、倒下并逐渐消失。损毁交通车和警车退出驾驶与碰撞；警车被击毁后，存活警员仍可下车追踪。倒下警员不能发现或截停玩家。自己的车沿用原有烟雾、损毁和重新停车机制，增加枪械命中。攻击人物会更快增加通缉。破坏车库墙与屋顶会移除相应碰撞，绿色地块仍可避风头。

破拆球命中外围实体使用真实 GPU 球位置的分段扫掠；原有体素墙的破拆预判继续保留。球的读取复用现有紧凑 GPU gather，不读取全城刚体缓冲，不引入另一套物理引擎。自动交通、人物与外围坍塌仍采用现有 CPU 行为和共享实例渲染。

新增本地存档 `city.expanded-damage.v1.<playerId>`，以稳定 ID 保存楼块生命值、坍塌状态和人物车辆受损状态。恢复前检查布局指纹、城市范围、合法道路与人物可站空间；拒绝非法数据时保持原来的金币、任务和体素损坏。刷新不重播破坏效果或重复给奖励。R 重建修复所有城市破坏并保留金币与车辆所有权。90 秒挑战的新增破坏不会覆盖自由模式存档。

拆除排行榜与委托金币仍沿用原有规则：新外围楼块、人物和交通车辆不提供额外排行积分或刷金币奖励。原有城市体素布局与存档键保持兼容。

验证采用真实桌面和触摸输入，覆盖枪击、激光打穿后步行、坍塌、人物与警车破坏、刷新和重建；单元测试覆盖全部楼体、网格射线、车辆旋转碰撞、原子恢复和有界碎屑，GPU 测试覆盖真实球位置读取。执行记录与截图位于本地 `artifacts/world-v08/`。
