# 可进入的暖色街区 v0.5

便利店位于东侧 (46,0)，双层住宅位于北侧 (0,46)，仓库位于东北 (46,46)。三栋替换对应外围背景地块；门洞、房间、楼板、楼梯、家具均直接建在同一个0.25m体素世界中。玩家正常步行进门，住宅左侧木梯可连续上下楼。13件家具分别作为独立对象；支撑楼板失去固定接触时，家具也会掉落。

按G打开「进屋任务」：便利店到柜台取件110金币，住宅上二楼取包裹150金币，仓库拆40块旧家具165金币。目标需要本人下车步行接近并满足实际高度，返回门口结算；三项各奖励一次。与街区随机委托互斥，奖励进入同一车库钱包。当前阶段和完成记录随存档恢复。

## 存档与重建

每个匿名玩家身份保存独立进度：金币、车辆、任务、人物和车辆位置，以及另一个建筑损坏快照。损坏快照按布局指纹和压缩体素索引保存；布局改变或数据损坏时不把索引套到其他墙体。保留旧v0.4钱包和车库数据，单独对账街区累计与室内奖励。

自由模式每2秒、暂停及离开页面保存。刷新恢复破洞和被拆掉的家具；动态散落碎块在恢复时清理，不重放爆炸。R及「重置」明确修复街区，保留钱包、购车和任务阶段/已领奖记录。浏览器写入失败会在菜单显示提示；存档没有跨浏览器/设备同步。

90秒挑战仍使用原本94,196个体素、原排行榜规则。进入挑战保存当前探索损坏并建立完整挑战世界；返回探索恢复其快照。模式重建排队，避免快速切换覆盖损坏；重建释放旧GPU球体资源。

## 规模与验证

新增24,419个体素：3个建筑外壳和13个家具对象。完整探索版118,615个体素，仍使用Three.js WebGPU和three-avbd。没有更换引擎，也没有导入第三方项目代码、模型或新依赖。室内建模、网格碎裂和体素分区的GitHub调研用于方案比较；这版直接编写自己的体素建筑。

104项规则/场景测试、3项GPU测试、类型检查和生产构建通过。桌面原生键盘完成三栋进屋、住宅上下楼及三任务425金币；触控模拟完成进屋与3.25m二楼路线。403个受损体素刷新后全部恢复为缺口，R修复保留任务奖励。真实GPU移除四个床脚下的楼板接触，222个床体素松脱一次，刷新床消失。临时生产地址通过普通URL实际取件、110金币、屋顶破洞159体素及刷新恢复后再推广至公开地址。

手机为浏览器触控/横竖屏模拟，未代表真实手机性能测试；当前不是全城室内或分区物理流式加载。原城市渲染仍约340万三角形，画质由设备校准选择，不保证所有设备60fps。
