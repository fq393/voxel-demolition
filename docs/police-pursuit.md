# 警察与仓库脱身

v0.7 延续暖色解压城市，加入两辆奶油/深蓝警车、制服警员和西侧实体安全车库。新增模型为本项目编写，沿用 Three.js 实例批次与 CPU 碰撞，不改破坏方块索引、旧损坏存档或排行榜规则。

开枪、爆炸、破坏与碰撞累计到三颗星；连续事件限频。警车沿道路追踪最近可见位置或新事件位置，失去视线后搜索，不会读隐藏玩家位置追踪。靠近步行目标后警员下车，绕车、找门并步行拦截；持续近距离且视线可达才截停。车库保护区内停留三秒清除通缉，飞行与楼上玩家不能被地面警员直接截停。被截停回车库重试，金币、建筑损坏和车辆保留。

G 菜单可关闭警察，继续自由拆除；90 秒排行榜挑战暂停警察与新任务。暂停、后台、重建不推进搜索或截停计时，刷新清除当前通缉。

“仓库脱身”是一次性 240 金币任务：步行取包裹，拆开西墙并真正走出或跳过碎屑穿出，再开自己的车回车库，解除通缉后交付。任务期间不能购买或切换车，通缉中不能召回车。刷新或 R 从取件重新尝试，已完成奖励保留。新奖励进入严格账本验证，旧版进度没有新字段时自动兼容。

功能组织参考 [grand-theg-auto-i 的 WantedSystem](https://github.com/joaonetovhc/grand-theg-auto-i/blob/main/src/systems/WantedSystem.js) 与 [TrafficSystem](https://github.com/joaonetovhc/grand-theg-auto-i/blob/main/src/systems/TrafficSystem.js)，该仓库根许可证核对为 MIT。此次没有复制其代码、角色模型或 GTA 素材；道路寻路、真实视线、警员碰撞、任务与渲染由本项目实现。

当前范围为两辆警车与两位警员，不含人物伤害、拘留系统、无限城市或联网警察。金币及城市损坏仍为当前浏览器本机存档。
